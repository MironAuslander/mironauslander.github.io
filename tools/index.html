⚡ Quick Actions

📋 How to Use

  1. Project Studio: Edit project details, images (thumbnail, cover, video poster) and media
  2. Layout & Assets Manager: Control featuring and visibility, check image assets at a glance
  3. Save Changes: Tools will download a backup JSON file
  4. Apply to Site: Replace projects-data.json with your backup
  5. Run Updates: Execute node scripts/run-all-updates.js from project root
